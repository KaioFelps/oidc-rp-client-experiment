# ODIC Client
Esse sistema é uma implementação super simples de um RP ([Relying Party]) utilizando
a biblioteca [oauth4webapi].

Serve meramente como um cliente de teste para o authorization server contido na
aplicação [lti-consumer-poc].

[Relying Party]: https://openid.net/developers/how-connect-works
[oauth4webapi]: https://github.com/panva/oauth4webapi
[lti-consumer-poc]: https://github.com/KaioFelps/lti-consumer-poc
